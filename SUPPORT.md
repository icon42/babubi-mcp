# Support

babubi-mcp is published in case it is useful to others, but it comes without support: there is no issue tracker, questions may go unanswered, and there is no commitment to fix bugs, to follow upstream releases or to keep publishing images. It is provided as is, without warranty of any kind, as stated in the [license](LICENSE).

For a supported MCP server, use [babybuddy-mcp](https://github.com/babybuddy/babybuddy-mcp), which babubi-mcp is forked from, together with [Baby Buddy](https://github.com/babybuddy/babybuddy).
